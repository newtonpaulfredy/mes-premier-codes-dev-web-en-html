DEFINITIONS

HTML
:
(Hyper Text Mark Up Langage) est le langage standar utilisé pour créer des pages we
CSS
:
(Cascading Style Sheets) est un langage de mise en forme utilisé pour décrire la presentation d'un document HTML
JAVASCRIPT
:
strest un langage de programmation qui permet de créer des interactions dynamique sur les pages web
URL
:
(Uniform Ressource Locator) est une adresse qui permet de localiser une ressource sur le web
HTTP
:
(Hyper Text Transfer Protocol) est un protocole de communication utilisé pour transférer des données sur le web
DHCP
:
(Dynamic Host Configuration Protocol) est un protocole de réseau qui permet de configurer automatiquement les parametres de réseau d'un ordinateur ou d'un appareil connecté au réseau
DNS
:
(Domain Name System) est un systeme qui permet de traduire les noms de domaine en adresse ip,afin de faciliter l'accès aux sites webet aux ressources en ligne
IP
:
(Internet Protocol) est un protocole de communication qui permet aux appareils de communiquer entre eux sur un réseau,notamment sur internet
