Introduction

ce manuel presente toutes les bases d'apprentissage du html du css et du javascript afin de créer une page web dynamique professionnelle et interactif et a travers ce manuel nous définissons aussi ce qu'est une adresse ip

les bases du Html

HTML signifie HyperText Markup Language. C’est le langage qui permet de structurer le contenu d’une page web.
• HTML ne sert pas à styliser la page ;
• HTML ne sert pas à ajouter l’interactivité avancée ;
• HTML sert à organiser le contenu :
— les titres ;
— les paragraphes ;
— les liens ;
— les sections ;
— les zones principales d’une page.>

css

(Cascading Style Sheets) est un langage de mise en forme utilisé pour décrire la presentation d'un document HTML

javascript

strest un langage de programmation qui permet de créer des interactions dynamique sur les pages web

adresse ip

(Internet Protocol) est un protocole de communication qui permet aux appareils de communiquer entre eux sur un réseau,notamment sur internet
